# 个人私域建设网站 · V1 方案（需求 + 技术方案 + 分期任务 + 验收标准）

> 面向：兼职设计师（潘老师，技术小白）。核心目标：**让网站帮你接单获客 + 展现物料专业度**。
> 原则：**先免费跑通，再逐步升级**。V1 不写复杂代码，用免费、成熟、可用的现成资源。

---

## 一、需求整理（大白话版）

### 1.1 这个网站是干嘛的？

一个"线上接单名片 + 物料百科全书 + 在线下单入口"，让你在微信生态里发出去之后：
- 客户看到你的**个人介绍**，知道你是谁、能做什么、为什么信你；
- 客户看到**后台也能展示的物料工艺细节**（发光字多厚、喷绘什么材料、印刷什么纸），显得你专业；
- 客户能**发起下单需求**，留下联系方式，你收到通知后微信跟进；
- 客户能通过**微信小商店/有赞**直接在线支付下单；

- （进阶）客户能直接跟 **AI 对话**，AI 帮他出设计初稿，你审核后交付。

### 1.2 核心模块清单

| # | 模块 | 内容 | 优先级 |
|---|------|------|--------|
| M1 | 个人主页/首屏 | 头像、姓名、一句话定位（如"10年广告物料老匠人，发光字/喷绘/印刷一站式"）、微信二维码、找我做单按钮 | P0 |
| M2 | 服务介绍 | 三大业务板块：广告设计、物料制作（发光字/灯箱）、喷绘写真、印刷品 | P0 |
| M3 | 物料百科 | 每种物料的**工艺参数表**（厚度/材质/工艺/光源/功率/适用场景/报价区间），这是你的差异化卖点 | P0 |
| M4 | 作品集 | 真实案例图集（可分类：门头发光字/室内写真/画册印刷），V1 先用占位图+说明 | P1 |
| M5 | 接单流程 | 4 步说清：提交需求 → 免费报价 → 打样确认 → 生产交货 | P0 |
| M6 | 在线下单 | 需求表单（免费版用腾讯问卷/金数据/Coze表单）+ 跳转微信小商店/有赞支付 | P0 |
| M7 | 拓客/合作入口 | 承接需求方 + 未来招募兼职设计师/渠道合作的入口 | P1 |
| M8 | AI 设计助手 | 网页右下角 AI 对话浮窗：由"扣子（Coze.cn）"免费搭建，自动接待客户咨询与设计需求 | P2 |
| M9 | 联系方式 | 微信/电话/地址，全站悬浮"加微信"按钮 | P0 |

### 1.3 关键产品决策（已与你确认）

1. **客户在国内** → 网站用 Cloudflare Pages 免费托管（国内可直接访问，速度可接受）；不备案、不买服务器。
2. **在线支付** → 不自建支付（要资质/要钱），V1 用**微信小商店 / 有赞 / 微店**这类免费第三方，网页放"去下单"按钮跳转。你开店上传商品即可收款。
3. **你是兼职设计师要接单** → 网站所有入口都导向"提交需求/加微信"，**AI 是未来的前台接待员**。
4. **AI 自动出设计稿（前台接待）** → 用 **扣子 Coze（字节跳动出品，免费）** 搭建。可做成网页嵌入对话框 + 绑定微信公众号自动回复。V1 先不做，V2 接入。
5. **你自己改内容** → V1 内容集中在一个 `content` 文件夹的配置文件里，改文字=改文件（我会教你，3 分钟学会），改完保存自动更新上线，不用懂代码。
6. **零预算** → 全程免费：Cloudflare Pages（免费托管）+ GitHub（免费仓库，可选）+ Coze（免费 AI）+ 腾讯问卷/金数据（免费表单）。

### 1.4 非目标（V1 不做）

- ❌ 不搭数据库、不做登录注册、不做订单管理系统（V1 用表单+微信人工跟进）
- ❌ 不做在线支付对接开发（V1 外链第三方商店）
- ❌ 不做 AI 自动出稿（V2）
- ❌ 不做多语言（V1 仅中文）
- ❌ 不买域名不备案（V1 用免费子域名，跑通后再升级 .com）

## 二、页面设计与技术方案

### 2.1 技术选型（免费 + 小白友好）

| 层 | 选型 | 为什么要这样 |
|----|------|-------------|
| 站点框架 | **纯静态站点（Astro 或最简 Vite + Tailwind）** | 静态站免费托管、打开快、设计感可塑性最强；无需后端 |
| 设计语言 | **Tailwind CSS + 自定义设计**，深色高端风/轻工业风 | 广告物料行业=视觉行业，网站本身就要"长得很专业" |
| 交互 | 滚动动效（滚动渐入）、分类筛选（物料/作品切换）、悬浮微信按钮、平滑锚点导航、移动端适配 | 满足"强大交互能力"诉求，但全部用纯前端现成组件，不折腾 |
| 托管 | **Cloudflare Pages（免费）** + GitHub（免费） | 国内可访问、免费、自动部署（你保存内容=自动更新上线） |
| 表单 | 腾讯问卷 / 金数据（免费版）嵌入 iframe 或链接 | 客户提交需求→你收到短信/微信提醒，零开发 |
| 支付 | 微信小商店 / 有赞 / 微店（免费开店） | 网页外链跳转，你在后台管商品和收款 |
| AI 客服 | **扣子 Coze.co（免费）**，V2 接入网页浮窗+公众号 | 国内免费可用的 AI Agent 平台，现成资源 |

> 为什么不用 WordPress / 建站平台（上线了/凡科/微搭）？：免费版强制带平台广告、域名是平台子域名、设计感被模板锁死、且数据在别人平台。**静态站+Cloudflare** 完全免费、无广告、设计自由、数据是你自己的文件。

### 2.2 网站信息架构（页面清单）

单页应用风格（V1 就 4~5 个页面，尽量简洁）：

```
首页 index.html
  ├─ 首屏 Hero：你的一句话定位 + 主按钮（"免费咨询报价"）
  ├─ 服务板块：广告设计 / 物料制作 / 喷绘写真 / 印刷品
  ├─ 物料百科预览：发光字 → 喷绘 → 印刷 三大卡片入口
  ├─ 作品集预览（4~6 张）
  ├─ 接单流程 4 步
  └─ 底部：联系方式 + 微信二维码 + 免责声明

页面2 物料百科 material.html
  ├─ 发光字详情页（或锚点区）：厚度/材质/工艺/光源/功率/寿命/适用场景/价格区间
  ├─ 灯箱、标识字
  ├─ 喷绘：户内写真 vs 户外喷绘（材质厚度/分辨率/防雨防晒/用途）
  └─ 印刷：铜版纸/卡纸/相纸/不干胶…克重与尺寸对照表

页面3 作品集 works.html（分类筛选：门头/招牌/展架/画册…）

页面4 下单页 order.html（需求表单 + 微信小商店跳转按钮 + 流程说明）
```

### 2.3 设计方向（V1 视觉基调）

- 配色：深灰/炭黑底 + 亮橙色或电光蓝点缀（广告行业常用"醒目光效"风格，呼应"发光字"）
- 字体：中文用思源黑体/阿里巴巴普惠体（免费商用），标题可做粗黑+渐变光效
- 动效：滚动渐入、卡片悬浮、发光描边效果——**呼应"发光字"业务**，把网页本身做成"发光效果展示墙"
- 移动端优先适配（微信里打开是主要场景）

## 三、分阶段开发任务（附工期估算）

### Phase 0 —— 准备工作（你来做，30 分钟，我全程电话/文字指导）
1. 注册 **GitHub** 账号（免费）→ 告诉我是哪个账号
2. 注册 **Cloudflare** 账号（免费）→ 绑定 GitHub 账号授权
3. （选做）注册 微信小商店 / 有赞 / 微店 账号，上传 2 个商品测试；注册 腾讯问卷 账号建 1 个"需求登记表"
4. 准备素材：你的头像照片、真实作品图 5~10 张（手机拍也可）、微信二维码截图、发光字/喷绘/印刷的工艺参数文字（我可以按行业通用标准帮你起草初稿，你确认）

### Phase 1 —— 网站搭建（agent 团队执行，约 1~2 个工作日）
1. 搭建项目骨架（Vite/Astro + Tailwind + 路由）
2. 完成首页 Hero / 服务板块 / 接单流程 / 底部联系
3. 完成物料百科页（发光字/喷绘/印刷三大区块+参数表）
4. 完成作品集页（分类筛选 + 占位图）
5. 完成下单页（腾讯问卷 iframe + 小商店外链按钮）
6. 全局交互：滚动动效/悬浮微信按钮/移动端适配/响应式
7. 部署上线：推送到 GitHub → Cloudflare Pages 自动部署 → 生成免费域名（xxx.pages.dev）→ 国内访问测试

### Phase 2 —— 内容与细节（agent 团队执行 + 你确认，约 1 个工作日）
1. 替换你的真实头像、作品、微信二维码
2. 物料参数表逐项核对（你提供初稿，我排版成专业表格）
3. SEO 基础优化：页面标题/描述/关键词（发光字价格、门头招牌制作、广告喷绘 等长尾词）
4. 性能检查与手机端真机测试

### Phase 3 —— 进阶功能（V2，先不急）
1. AI 设计助手：扣子 Coze 搭建"设计咨询机器人"→ 网页右下角浮窗接入 + 绑定微信公众号
2. 微信小商店建立首个真实商品 + 页面价格联动
3. 数据统计（Cloudflare 自带免费统计）
