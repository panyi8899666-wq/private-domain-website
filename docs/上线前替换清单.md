## 五、改完内容后如何发布 🚀

1. **保存**：所有 `content/` 下的 JSON 改动，记得按 `Cmd + S` 保存（改哪个存哪个，不用一次全改完）。
2. **重新生成网站**：打开「终端」（Mac 上叫 Terminal），输入以下命令后按回车（先输第一条）：
   ```bash
   npm run build
   ```
   命令会自动把最新的内容重新生成到 `dist/` 文件夹。看到类似 `done` 且绿色、没有红色报错，就说明生成成功。
3. **本地预览确认效果**（可选但推荐）：
   ```bash
   npm run preview
   ```
   然后根据终端提示的地址（通常是 `http://localhost:4321`），在浏览器里打开，**自己把每一页点一遍**，重点检查：微信二维码扫得出吗？「复制微信号」按钮能复制 17306983179 吗？微信沟通/下单指引清楚吗？作品图都显示了吗？——确认没问题再上线。
4. **正式上线**：把 `dist/` 文件夹里的全部文件上传到你的托管平台（如 GitHub Pages / Vercel / 云服务器）即可。如果已有自动部署（如 GitHub 连接），通常 `git push` 后会自动发布。

> 💡 **多改多检查**：每次改完都跑一遍 `npm run build`，如果页面还是旧内容，多半是忘记保存或 build 没跑成功。
