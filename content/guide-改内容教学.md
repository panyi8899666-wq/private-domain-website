# 《改内容教学：3 分钟学会改网站内容》

> 你好！这份文档教你不懂代码也能自己改网站内容。网站所有文字、图片、链接都放在 `content/` 文件夹里，**改文件 = 改网站**，改完保存并发布，网站就自动更新了。全部操作只需要两样东西：**一个文本编辑器**（记事本也行）和 **GitHub Desktop**（见图 0-1 安装方法）。

---

## 0. 课前准备（装好工具，只需一次）

要开始改内容，你需要能够**打开文件**和**把修改发到网上**。推荐最简单的两条路，任选其一：

**方法 A：GitHub 网页在线改（零安装，手机上都能改）**

1. 浏览器打开你的 GitHub 仓库页面（类似 `github.com/你的名字/private-domain-website`）；
2. 点进 `content/` 文件夹 → 点开一个 JSON 文件（比如 `home.json`）；
3. 点右上角铅笔图标 ✏️ 进入编辑；
4. 改完点 **Commit changes** → 输入一句说明 → 再点 **Commit changes**。

**方法 B：GitHub Desktop 本地改（推荐，可批量改）**

1. 下载安装 GitHub Desktop（免费）：https://desktop.github.com；
2. 打开后登录你的 GitHub 账号，把你的网站仓库 Clone 到电脑（点 File → Clone repository）；
3. 用系统自带「文本编辑/记事本」打开 `content/` 下的文件修改；
4. 改完回到 GitHub Desktop，左下角写一句说明 → 点 **Commit to main** → 点 **Push origin**。

> 不管是方法 A 还是方法 B，**改完推送到 GitHub 后，网站大约 1~2 分钟内自动更新上线**（第 6 章有验证方法）。

## 1. 改首页文案（示例：改一句服务简介）

**要改什么**：首页「服务板块」里四个卡片的介绍文字。
**打开哪个文件**：`content/home.json`。
**找哪个字段**：往下滚到 `"services"` 这一段，找到 `"desc"` 字段。

改之前长这样：

```json
{ "name": "广告设计", "icon": "pen-tool", "desc": "logo/海报/画册设计，改到满意为止", "href": "/material#fashezi" }
```

改成你要的字（只改引号里的文字，别动英文键名和逗号）：

```json
{ "name": "广告设计", "icon": "pen-tool", "desc": "设计改到你满意为止", "href": "/material#fashezi" }
```

**常见修改点速查表**：

| 想改哪块 | 打开文件 | 找哪个键 |
| --- | --- | --- |
| 首页大标题/副标题 | `content/home.json` | `"hero"` 里的 `"title"` / `"subtitle"` |
| 首页小标签 | `home.json` | `hero.badge` |
| 服务四个卡片 | `home.json` | `services.items` |
| 首页百科预览三张卡 | `home.json` | `materialPreview.cards` |
| 首页展示几个作品 | `home.json` | `worksPreview.count`（只填 4~6） |
| 接单流程四步文字 | `home.json` | `process.steps` |
| 电话/地址/时间 | `content/site.json` | `contact` |

**保存发布**：按第 6 章步骤 push。
**怎么验证**：刷新网站首页，找到对应位置查看新文字。

> ⚠️ 注意事项：文字必须写在**英文双引号里**（`"`），键名（冒号左边的英文）和逗号、花括号一个都不能删。

## 2. 更换微信二维码 / 微信号

**要改什么**：网站页脚和悬浮「加微信」弹窗里的二维码图片和微信号。
**打开哪个文件**：`content/site.json`。
**找哪个字段**：找到 `"wechat"` 这段。

二维码图片的更换分两步：

**第 1 步：准备图片文件**

1. 在微信「我 → 二维码名片」里保存你的微信二维码图片；
2. 把图片转成 PNG 格式（可在微信里直接截图保存）；
3. 建议长边 ≥ 400 像素（太小扫不出来）；
4. 把图片文件放入 `public/images/qr/` 文件夹，命名为 `wechat.png`（**覆盖**原来的占位文件即可，最简单）；
5. 如果你想用别的文件名，比如 `my-qr.png`，那就把下面 `qrImage` 的值改成 `/images/qr/my-qr.png`。

**第 2 步：改微信号文字**（这样访客搜索微信号也能加到你）：

```json
"wechat": {
  "wechatId": "替换成你的微信号",       ← 比如 pan-gong-ad
  "qrImage": "/images/qr/wechat.png",
  "qrAlt": "扫码添加潘工微信，免费咨询报价"
}
```

**保存发布**：按第 6 章 push。
**怎么验证**：到网站底部看看二维码是否变成新图；用另一台手机微信扫一扫能否加上。

> ⚠️ 常见错误：图片路径写错（比如少写了文件夹名 `qr`）会导致图片加载失败。路径必须从 `/images/` 开头，和 `public/images/` 里的实际位置一一对应。

## 3. 新增或删除一个作品

**要改什么**：作品集页和首页「最近作品」里的作品。
**打开哪个文件**：`content/works.json`。
**找哪个字段**：`items` 数组里的每一个 `{ }` 就是一个作品。

**新增作品 = 复制一个 `{ }` 然后改值**（第 3 步就是这么简单）：

找到任意一个作品的花括号 `{ }`，**从 `{` 复制到 `}`**，粘贴在它下面，然后改内容：

```json
{
  "id": "w011",                                   ← 改成没重复的编号
  "name": "你的新项目名字",                        ← 项目名（访客看到的主标题）
  "category": "mentou",                          ← 分类：mentou门头/zhaopai招牌/zhanjia展架/huace画册
  "image": "/images/works/w011.svg",             ← 图片路径（图片放 public/images/works/ 文件夹）
  "alt": "用一句话描述这张图（给搜索引擎和读屏用的）",
  "note": "2026-10 完成 · 参数说明",
  "featured": true                               ← true=首页优先展示；false=只在作品集页
}
```

**删除作品**：把对应整个 `{ }`（含逗号）删掉即可。

**如果图片想换**：把新图片放进 `public/images/works/`，并把 `image` 的值改成对应文件名。

**保存发布**：按第 6 章 push。
**怎么验证**：打开作品集页，看新作品是否出现、分类筛选是否正常。

> 💡 提示：想让首页「最近作品」多显示/少显示，改 `content/home.json` 的 `worksPreview.count`（4~6 之间）。

## 4. 修改物料百科数据（发光字参数 / 喷绘、印刷对照表）

### 4.1 改发光字八项参数

**打开文件**：`content/materials/fashezi.json`。
**找字段**：`params` 数组里的每一项是 `{ "name": "参数名", "value": "参数值", "note": "补充说明" }`。
**怎么改**：只改 `value` 和 `note` 的文字。

> ⚠️ 注意：`params` 里的 **8 项（厚度/材质/工艺/光源/功率/寿命/适用场景/价格区间）一个都不能删**，这是需求要求（REQ-012）。可以加新项，但别删旧的。

### 4.2 改喷绘对照表（户内 vs 户外）

**打开文件**：`content/materials/penhui.json`。
**找字段**：`rows` 数组里每一行是一个比较维度：

```json
{ "dimension": "材质厚度", "indoor": "户内的文字", "outdoor": "户外的文字" }
```

只改引号里的文字；**行（4 行）和列不要增删**。

### 4.3 改印刷对照表（克重与尺寸）

**打开文件**：`content/materials/yinshua.json`。
**找字段**：`rows` 里的每一行：

```json
{ "material": "铜版纸", "weight": "128g / 157g / 200g", "sizes": "A4/A3、210×285mm 彩页" }
```

**怎么改**：改 `weight`（克重）和 `sizes`（可印尺寸）。四类材质（铜版纸/卡纸/相纸/不干胶）至少要保留这四行。

**保存发布**：按第 6 章 push。
**怎么验证**：打开「物料百科」页，滚动到对应表格检查新内容。手机上可以左右滑动表格查看。

## 5. 修改下单页问卷与小商店链接

**要改什么**：下单页的「需求表」地址和「去微信小商店下单」按钮跳转地址。

**打开文件**：`content/order.json`（下单页）和 `content/site.json`（全站默认）。

### 5.1 换需求表单（腾讯问卷/金数据）

1. 在腾讯问卷/金数据后台创建好你的需求表，复制问卷链接；
2. 找到 `content/order.json` 的 `form` 段，替换三处：

```json
"form": {
  "embedUrl": "https://wj.qq.com/你的问卷地址",            ← 页面内嵌表单
  "fallbackUrl": "https://wj.qq.com/你的问卷地址",          ← 打不开时的兜底按钮（必须填，不能空）
  "fallbackText": "打不开问卷？点这里直接填写需求表",
  "iframeTitle": "需求登记表"
}
```

> ⚠️ `fallbackUrl` 是兜底通道（需求要求必填），不论问卷打得开打不开都要保留这个按钮。

### 5.2 换微信小商店链接

1. 在微信小商店/有赞/微店后台复制你的店铺链接；
2. 替换 `content/order.json` 的 `store.url`：

```json
"store": {
  "title": "去微信小商店下单付款",
  "url": "https://你的小商店链接",
  "note": "由平台担保交易，支持微信支付"
}
```

> ⚠️ 本站只放链接、不做收款、不处理金额。支付、退款、订单全部由第三方小商店承接（需求 REQ-027）。

**保存发布**：按第 6 章 push。
**怎么验证**：打开下单页，点「去微信小商店下单付款」看是否跳到你的店铺；点「填写需求表」看能否打开问卷。

## 6. 保存并发布（push）——改完自动上线

**核心一句话：改完文件 → 上传（push）到 GitHub → 网站自动更新。**

1. **网页在线改**（方法 A）：文件改完点绿色 **Commit changes** 即可，网页会直接帮你上传；
2. **GitHub Desktop**（方法 B）：
   - 打开 GitHub Desktop，左侧会列出你改过的文件；
   - 左下角「Summary」框写一句说明（如「改首页标语」）；
   - 点 **Commit to main**；
   - 再点右上角 **Push origin**（上传）。

3. **等 1~2 分钟**：Cloudflare Pages 检测到更新会自动重新构建网站。

**怎么验证已上线**：
- 刷新你的网站页面（`你的域名.pages.dev`）；
- 手机微信里如果看不到变化，是微信缓存，**关闭页面重进**，或在网址末尾加 `?v=1` 再打开。

## 7. 常见错误怎么避免

| 症状 | 原因 | 解决办法 |
| --- | --- | --- |
| 网站变旧 / 打了半天没更新 | 部署还没完成，或浏览器缓存 | 等 1~2 分钟；强刷（Ctrl/Cmd+Shift+R）或加 `?v=2` 刷新 |
| 网页变成空白 / 发布失败 | JSON 多打了逗号、少了引号、花括号不配对 | 打开文件看看有没有 `,,` 连续逗号；引号必须是英文 `"`；每个 `{` 都要有对应的 `}`。修复后重新 push |
| 图片显示不出来 | 图片路径写错，或文件没放进对应文件夹 | 检查 `image`/`qrImage` 的值是否以 `/images/` 开头，且 `public/images/` 下真有这个文件（文件名大小写要一致） |
| 改了没效果，但文件在变 | 改错了文件/字段 | 对照本「教学」速查表确认改的文件和键名对不对 |
| 删除云端文件？ | — | 直接删文件 → Commit → 自动上线 |

> ⚠️ 记住 JSON 三大铁律：
> 1. **键名和值都必须用英文双引号**（`"`），不能用中文引号；后一个键之间要加英文逗号 `,`；最后一项后面**不能有逗号**；
> 2. `_` 开头的键是说明文字（如 `_说明`），随便改，删了也不影响功能，但建议留着提醒自己；
> 3. 拿不准时，复制一份完整 `{ }` 再改名字，比从零写更不容易错。
